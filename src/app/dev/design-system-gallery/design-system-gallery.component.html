Background Mesh — DS-component-background-mesh

Comparar via get_screenshot contra os nós Figma mobile (4360:7158/4360:7165) e desktop (4366:9534) (quickstart.md § Validação 2). O componente usa position: fixed — o quadro abaixo tem transform: translateZ(0), que por spec do CSS cria um novo containing block para elementos fixed descendentes, confinando a pré-visualização ao quadro em vez de cobrir a página inteira (a implementação real do componente continua fixa à viewport quando usada sem esse wrapper). Redimensionar o quadro/navegador para conferir o comportamento responsivo; emular prefers-reduced-motion: reduce no DevTools para conferir que os 3 blobs param de se mover.

Input Chat — DS-component-input-chat

Campo de mensagem da assistente de IA. Digitar até passar de uma linha: o campo cresce para cima e o botão permanece colado na base. A partir de ~7 linhas ele trava em 160px e ganha barra de rolagem dentro da borda arredondada, sem cobrir o texto. Ao digitar o primeiro caractere o botão troca de face (gravar → enviar) sem mudar de posição.

Bottom Nav Bar — DS-component-bottom-nav-bar

Esta é a única entrada documental da galeria: o componente já está visível no rodapé desta própria página, montado uma única vez pelo shell da aplicação (app.component.html). Instanciá-lo aqui criaria uma segunda barra fixa sobreposta à primeira, o que o contrato do componente proíbe explicitamente (specs/ds/DS-component-bottom-nav-bar/contracts/bottom-nav-bar-api.md).

Para conferir: comparar via get_screenshot contra o nó Figma 2265:1390; redimensionar o navegador nas larguras 671px (100% da largura), 672px e 1199px (640px centralizada, acompanhando o page-container) e 1200px (a barra some e o nav-menu lateral assume). O símbolo da IA transborda 8px acima da barra de propósito — nenhum ancestral pode ter overflow: hidden. Roteiro completo em specs/ds/DS-component-bottom-nav-bar/quickstart.md.

Bottom Sheet — DS-component-bottom-sheet

Única superfície modal do produto em celular e tablet. É um chassi: cabeçalho fixo de arraste, conteúdo rolável projetado e rodapé projetado — quem monta a conversa é o consumidor. A composição abaixo reproduz o nó Figma 4412:5973 (mensagem de abertura + 2 atalhos + input-chat) e existe para a verificação de fidelidade; ela não faz parte do design system.

Só renderiza em xs/sm (<1200px). Em desktop ele não é montado — nem o elemento host existe no DOM (FR-014). Para testar, estreite a janela para ~402px: o botão abaixo passa a abrir o sheet.

Encaixe atual: {{ sheetSnap() }} — último evento: {{ sheetLastEvent() }}

Arrastar o cabeçalho para baixo dispensa (o scrim clareia durante o gesto); para cima expande para full sem deslocar o container (FR-028). Esc, o X e o toque no scrim também dispensam. Roteiro completo em specs/ds/DS-component-bottom-sheet/quickstart.md.

Drawer — DS-component-drawer

Par de desktop do bottom-sheet: mesma proposta (chat da IA + atalhos), mas painel fixo ancorado à direita, sem scrim, que reserva espaço do conteúdo em vez de sobrepô-lo. A composição abaixo reproduz o nó Figma 4412:5749 (mensagem de abertura + 2 atalhos + input-chat) e existe para a verificação de fidelidade; ela não faz parte do design system.

Só renderiza em md (≥1200px). Em celular/tablet ele não é montado — nem o elemento host existe no DOM (FR-013). Alargue a janela para testar.

Largura atual: {{ drawerSnap() }} — último evento: {{ drawerLastEvent() }}

O botão de expandir alterna a largura entre default (480px) e expanded (tela cheia menos o rail de navegação) — sem nenhuma animação. Em expanded ele vira modal (foco preso, conteúdo por trás inerte); em default a página continua totalmente interativa. Esc nunca fecha nem recolhe. Roteiro completo em specs/ds/DS-component-drawer/quickstart.md.
